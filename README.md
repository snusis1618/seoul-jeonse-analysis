# 서울시 전세 보증금 변화 분석 · 2021–2025

스마트도시계획 데이터 분석 과제입니다. 계약일 기준 2021~2025년 서울시 전세 자료를 분석합니다.

## 제출물
- `index.html`: Cloudflare 배포용 대시보드. 내려받아 브라우저에서 직접 열어도 작동합니다.
- `서울시_전세가격분석.ipynb`: 실행 결과가 포함된 Jupyter Notebook입니다.
- `개별그래프_HTML/`: Notebook의 `fig.write_html()`로 저장한 Plotly 그래프 3개입니다.
- `집계표/`: 전처리 요약, 월별·연간 통계, 중복 처리 전후 비교표입니다.
- `재현코드/`: 전처리와 대시보드 생성 코드, 화면 소스, 지도 출처입니다.

## 분석 기준
계약별 보증금(만원)을 임대면적(㎡)으로 나눈 값의 중앙값을 사용합니다. 월별·연간 값은 각 기간의 관측에서 직접 계산합니다. 공식 가격지수나 동일 주택의 가격 변화를 의미하지 않습니다.

원본 23개 컬럼의 값이 전부 일치하는 추가 기록만 제거하고 첫 행을 유지했습니다. 일부 주소·날짜·가격만 같은 기록은 유지했습니다. 분석 관측은 1,279,501행이며, 2025년은 234,181행입니다. 연간 중앙값은 2021년 590.04만원/㎡에서 2025년 673.32만원/㎡로 14.11% 높아졌습니다.

## 재실행
원자료 5개는 용량 때문에 GitHub에 포함하지 않았습니다. 작성자가 별도로 보관하는 원자료를 다음 경로에 넣어야 Notebook과 전체 생성 코드를 다시 실행할 수 있습니다.

```text
자료/서울특별시_전월세가_2021.txt
자료/서울특별시_전월세가_2022.csv
자료/서울특별시_전월세가_2023.csv
자료/서울특별시_전월세가_2024.csv
자료/서울특별시_전월세가_2025.csv
```

```sh
python -m pip install -r 재현코드/requirements.txt
python 재현코드/generate_dashboard.py
```

Notebook은 저장소 루트를 작업 폴더로 열고 전체 실행합니다. 원자료 없이 포함된 집계자료로 대시보드를 다시 조립하려면 다음 명령을 사용합니다.

```sh
python 재현코드/generate_dashboard.py --render-only
```

생성 결과는 `재실행결과/`에 저장됩니다. `index.html`과 완성 HTML을 열어 보는 데는 Python이나 원자료가 필요하지 않습니다.

자료: 서울 열린데이터광장의 서울시 부동산 전월세가 자료. 지도 출처·라이선스와 분석 한계는 대시보드의 ‘해석 방법’ 탭과 `재현코드/geography/`에 기록했습니다.
